- 화면: 패널의 **우리 조** 선택(기기에 기억) → "복구 필요" 구역 카드에서 카메라 스캔 → 구역이 "복구 중"/"복구됨". 취소는 우리 조 제출만 가능. 2026-10-13 사용자 요청으로 Scaniverse 링크 입력·"Scaniverse에서 보기"·크레딧, 현황판의 도로그램 이동 링크·"큰 화면으로 보기" 버튼을 모두 없앴다(서버의 링크 제출 API는 남아 있음). 큰 화면 모드(`?view=screen`)는 주소로만 열고 오른쪽 아래 "큰 화면 끝내기"로 나온다.
