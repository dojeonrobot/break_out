## 진행과 저장

- 좌표 획득, 배전반 연결, 잔재 파괴는 기록 수를 늘리지 않는다. 캠퍼스 세 기록과 섬 두 기록만 센다.
- 스캔 링크가 변환 중이거나 오류 상태이면 다음 활동을 열지 않는다. 오류 문구를 확인해 링크를 다시 제출한다.
- 섬의 촬영 결과는 미션 완료와 별도로 태블릿별 서버 `records.q1`, `records.q2`에 저장한다. 촬영 뒤 대화를 닫거나 재접속해도 기록을 다시 찍지 않는다. 저장 실패 시 같은 화면에서 재시도한다.
- 과거 버전에서 미션 1·2를 이미 끝낸 조는 기존 기록을 유지한다. 신규 태블릿은 조의 기록과 진행 상태를 이어받는다.
- 다음 활동 카드는 같은 조의 최근 10분 이내 접속 태블릿이 미션을 끝낼 때 열린다. 네이티 기록을 찍었다고 분석과 조별 대기를 건너뛰지 않는다.
- 전원은 배전반 성공 순간 별도 저장한다. 이후 기록 수집 때 개별 놀이기구를 다시 켜지 않는다.
- 실패한 가상 시험은 선택 순서·양·결과를 누적하며 실제 섬에는 영향을 주지 않는다. 시험 성공과 실제 환원 완료는 별도 상태다.
- 「보이드」는 현재 세부 활동을 안내한다. 「‹ 이전」은 대사를 다시 보여 주고 Space 또는 탭으로 진행한다.
- 「처음부터」는 해당 조의 제출과 활동 상태를 초기화한다. 다른 조에는 영향을 주지 않는다.

## 화면과 검증 범위

기록 패널은 캠퍼스에서만 기본 표시한다. 섬에서는 중앙의 미션 안내를 사용한다. PC와 태블릿 가로·세로·짧은 화면 크기에서 미로 시점, 네이티 초상화, 촬영 버튼, 분석 및 완료 카드의 표시를 확인한다. 화면 크기 모사는 실제 태블릿 성능 측정과 구분한다.
