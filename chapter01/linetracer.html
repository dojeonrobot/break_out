1 연결 및 코드 업로드

처음 한 번은 USB로 코드를 업로드하세요.
그다음부터는 사파리 자동차 Wi-⁠Fi에 연결해 대시보드를 보고, 코드도 무선으로 업로드합니다.

처음 한 번: USB 업로드

사파리 자동차가 Wi-⁠Fi를 만들려면 이 코드가 먼저 업로드되어 있어야 합니다.
이미 업로드했다면 다음 단계로 넘어가세요.

  1. 코드 다운로드

    상단 코드 다운로드 버튼을 누르세요.
    압축을 풀고 .ino 파일을 여세요.
    폴더 안 파일은 삭제하지 마세요.

  2. 보드 및 포트 선택

    esp32 보드 패키지를 설치하세요.
    사파리 자동차를 USB로 연결하세요.
    [툴]에서 보드와 포트를 선택하세요.

  3. 업로드 실행

    [업로드] 버튼을 누르세요.
    완료되면 USB를 분리하세요.
    이제 전원을 켜면 Wi-⁠Fi가 생성됩니다.

사파리 자동차 Wi-⁠Fi 접속

공유기나 인터넷 연결은 필요하지 않습니다.

  1. 전원 켜기

    사파리 자동차 전원을 켜세요.
    잠시 뒤 Wi-⁠Fi가 생성됩니다.

  2. Wi-⁠Fi 연결

    을 선택하세요.
    비밀번호 을 입력하세요.

  3. 대시보드 접속

    상단 대시보드 접속 버튼을 누르세요.
    또는 주소창에 아래 주소를 입력하세요.
    http://

이 페이지를 먼저 열어 둔 뒤 사파리 자동차 Wi-⁠Fi로 전환하세요.
자동차 Wi-⁠Fi는 인터넷이 연결되지 않아 이 페이지를 새로 열 수 없습니다.

"인터넷에 연결되어 있지 않음" 알림이 표시되면 연결 유지를 선택하세요.

두 번째부터: 무선 업로드 (OTA)

코드를 수정한 뒤에는 USB 없이 Wi-⁠Fi로 업로드하세요.
완료한 단계에 체크하세요.

파일 삭제 금지

무선 업로드 기능은 코드 안에 있습니다.
ota_ap.h 등의 파일을 삭제하면
이후에는 USB로만 업로드할 수 있습니다.

2 대시보드 확인 방법

대시보드는 사파리 자동차의 센서 값과 동작을 실시간으로 보여줍니다.
주행 문제를 찾거나 값을 조정할 때 확인하세요.

  1. 1
    연결 상태

    초록색 연결됨이면 정상입니다.
    "최근 업로드"는 마지막 무선 업로드에 걸린 시간입니다.

  2. 2
    현재 동작

    사파리 자동차가 지금 선택한 동작입니다.
    그림의 기울기로 회전 방향을 보여줍니다.

  3. 3
    센서 값

    왼쪽·가운데·오른쪽 센서의 측정값(0~4095)입니다.
    기준값 500보다 크면 선으로 판단합니다.

  4. 4
    센서 표시등

    불이 켜지면 흰 바닥, 꺼지면 검은 선을 감지한 상태입니다.

  5. 5
    로그 필터

    화살표 버튼을 누르면 그 동작의 로그만 강조합니다.
    깔때기 버튼을 켜면 나머지 로그는 숨깁니다.

  6. 6
    로그 도구

    자동 스크롤, 시간 표시, 로그 지우기 버튼입니다.

  7. 7
    주행 로그

    0.1초마다 한 줄씩 기록됩니다.
    한 줄의 의미는 아래와 같습니다.

로그 한 줄 읽는 법
|RAW| 120 3480 98 |LINE| 010 | 직진
120 3480 98
센서 값 (왼쪽 가운데 오른쪽)
010
선 감지 패턴 (1 = 검은 선)
직진
패턴에 따라 선택된 동작

이 순서로 점검하세요

  1. 센서 점검

    사파리 자동차를 흰 바닥과 검은 선 위에 번갈아 놓으세요.
    두 값이 크게 차이 나고, 500이 그 사이에 있으면 정상입니다.

  2. 동작 점검

    바퀴가 뜨도록 자동차를 들고 선 위에서 좌우로 움직이세요.
    선 위치에 따라 현재 동작이 바뀌는지 확인하세요.

  3. 주행 점검

    트랙을 달리게 한 뒤, 로그에서 선을 벗어나기 직전 동작을 찾으세요.
    그 동작의 속도 값을 3번에서 조정하세요.

3 센서 및 속도 튜닝

센서가 선을 읽는 방식과 모터 속도의 관계를 이해하세요.
그다음 코드를 수정해 주행을 개선하세요.

센서 동작 원리

바닥의 센서 3개(왼쪽 L, 가운데 C, 오른쪽 R)는 검은 선 위에서 1, 흰 바닥에서 0으로 인식합니다.
아래 센서 버튼을 눌러 패턴별 동작을 확인하세요.

검은색 = 선을 감지한 센서

센서 패턴
010
자동차 동작
직진

선이 가운데에 있습니다.

왼쪽 모터
200
오른쪽 모터
200
setMotorSpeed(200, 200);
선 인식이 불안정한 경우: 센서 기준값 조정

센서 값의 범위는 0~4095이며, 기준값 500보다 크면 선으로 판단합니다.
대시보드의 LEFT / CENTER / RIGHT 값을 흰 바닥과 검은 선 위에서 각각 확인한 뒤,
두 값의 중간값으로 변경하세요.

// safari_linetracer.ino 28~30번째 줄
int TH_L = 500;
int TH_C = 500;
int TH_R = 500;

검은 선에서 값이 오히려 작아지는 센서라면 LINE_IS_DARK_LOW를 true로 변경하세요.

모터 속도 조정

setMotorSpeed(왼쪽, 오른쪽)의 입력 범위는 -255~255이며, 음수는 역회전입니다.
왼쪽으로 회전하려면 왼쪽 바퀴 속도를 낮추세요.

220~240으로 올리세요

직진(010) 두 값을
180으로 낮추세요

느린 쪽 바퀴 60을

완만한 커브에서 덜 꺾이는 경우

급커브에서 이탈하는 경우

느린 쪽 바퀴를 0(정지) 또는
-60(역회전)으로 낮추세요

선을 놓친 뒤 복귀하지 못하는 경우

후진(000)에서
한쪽 바퀴만 역회전하도록 변경하세요

코드 수정 방법

모터 속도는 safari_linetracer.ino의 142~157번째 줄에 있습니다.

  1. 1
    코드 위치 찾기

    Ctrl + F로 5ms 주기를 검색하세요.

  2. 2
    숫자만 수정

    바꾸려는 동작 줄에서 괄호 안의 두 숫자만 바꾸세요.
    앞 숫자는 왼쪽, 뒤 숫자는 오른쪽 바퀴입니다.

  3. 3
    저장 후 업로드

    Ctrl + S로 저장하고 무선으로 업로드하세요.

  4. 4
    결과 확인

    대시보드와 트랙 주행으로 결과를 확인하세요.
    완주 시간은 아래 완주 기록에 남기세요.

// ===== 5ms 주기 모터 제어 로직 =====
if (!L && C && !R) {        // 010 직진
  setMotorSpeed(200, 200);
} else if (L && !C && !R) { // 100 좌회전 더
  setMotorSpeed(40, 200);
} else if (L && C && !R) {  // 110 좌회전
  setMotorSpeed(60, 200);
} else if (!L && C && R) {  // 011 우회전
  setMotorSpeed(200, 60);
} else if (!L && !C && R) { // 001 우회전 더
  setMotorSpeed(200, 40);
} else if (L && C && R) {   // 111 정지
  setMotorSpeed(0, 0);
} else {                    // 000 후진
  setMotorSpeed(-200, -200);
}
왼쪽 바퀴 속도 오른쪽 바퀴 속도

한 번에 한 가지 값만 바꾸세요.
괄호와 세미콜론(;)을 지우면 업로드 오류가 발생합니다.

문제 해결

Wi-⁠Fi 목록에 사파리 자동차가 보이지 않는 경우

먼저 코드가 업로드되었는지 확인하세요(1번).
업로드되어 있다면 전원과 배터리를 확인한 뒤 사파리 자동차를 재부팅하세요.

비밀번호 오류가 표시되는 경우

비밀번호는 입니다.
영문 소문자와 숫자 0을 정확히 입력했는지 확인하세요.

대시보드에 접속되지 않는 경우
  • 현재 사파리 자동차 Wi-⁠Fi에 연결되어 있는지 확인하세요.
  • 주소를 http://과 같이 http://까지 입력하세요.
    https로 접속하면 열리지 않습니다.
  • 휴대폰이나 태블릿은 모바일 데이터를 끈 뒤 다시 시도하세요.
대시보드 연결이 끊기는 경우

사파리 자동차 1대당 대시보드는 최대 4개 창까지 연결됩니다.
다른 기기에서 열어 둔 창을 닫으세요.

USB 연결 후 COM 포트가 보이지 않는 경우

데이터 전송용 USB 케이블인지 확인하고 다른 USB 포트에 연결해 보세요.
그래도 보이지 않으면 보드의 USB 드라이버를 설치하세요.

Arduino IDE에 네트워크 포트가 보이지 않는 경우

노트북이 자동차 Wi-⁠Fi에 연결되어 있는지 확인한 뒤 Arduino IDE를 재시작하세요.

비밀번호가 8자 미만이면 비밀번호 없는 공개 Wi-⁠Fi로 생성됩니다.
