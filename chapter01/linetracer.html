1 아두이노 코드 업로드

보드에서 Wi-⁠Fi를 잡기 위해 safari_linetracer.ino 파일을 USB로 업로드해 주세요.
파일 업로드가 완료되었다면 2번으로 넘어가세요.

  1. 코드 다운로드

    상단 코드 다운로드 버튼을 누르세요.
    압축을 풀고 .ino 파일을 여세요.
    폴더 안 파일은 삭제하지 마세요.

  2. 보드 및 포트 선택

    esp32 보드 패키지를 설치하세요.
    로봇을 USB로 연결하세요.
    [툴]에서 보드와 포트를 선택하세요.

  3. 업로드 실행

    [업로드] 버튼을 누르세요.
    완료되면 USB를 분리하세요.
    이제 전원을 켜면 Wi-⁠Fi가 생성됩니다.

2 로봇 Wi-⁠Fi 접속

  1. 전원 켜기

    로봇 전원을 켜면 Wi-⁠Fi가 생성됩니다.
    인터넷 연결은 필요하지 않습니다.

  2. Wi-⁠Fi 연결

    을 선택하세요.
    비밀번호 을 입력하세요.

  3. 대시보드 접속

    상단 대시보드 접속 버튼을 누르세요.
    또는 주소창에 아래 주소를 입력하세요.
    http://

이 페이지를 먼저 열어 둔 뒤 로봇 Wi-⁠Fi로 전환하세요.
로봇 Wi-⁠Fi는 인터넷이 연결되지 않아 이 페이지를 새로 열 수 없습니다.

"인터넷에 연결되어 있지 않음" 알림이 표시되면 연결 유지를 선택하세요.

3 센서 동작 원리

바닥의 센서 3개(왼쪽 L, 가운데 C, 오른쪽 R)는 검은 선 위에서 1, 흰 바닥에서 0으로 인식합니다.
아래 센서 버튼을 눌러 패턴별 로봇 동작을 확인하세요.

검은색 = 선을 감지한 센서

센서 패턴
010
로봇 동작
직진

선이 가운데에 있습니다.

왼쪽 모터
200
오른쪽 모터
200
setMotorSpeed(200, 200);
선 인식이 불안정한 경우: 센서 기준값 조정

센서 값의 범위는 0~4095이며, 기준값 500보다 크면 선으로 판단합니다.
대시보드의 LEFT / CENTER / RIGHT 값을 흰 바닥과 검은 선 위에서 각각 확인한 뒤,
두 값의 중간값으로 변경하세요.

// safari_linetracer.ino 28~30번째 줄
int TH_L = 500;
int TH_C = 500;
int TH_R = 500;

검은 선에서 값이 오히려 작아지는 센서라면 LINE_IS_DARK_LOW를 true로 변경하세요.

4 모터 속도 튜닝

safari_linetracer.ino 143~158번째 줄의 setMotorSpeed(왼쪽, 오른쪽) 값을 수정하세요.
입력 범위는 -255~255이며, 음수는 역회전입니다.
왼쪽으로 회전하려면 왼쪽 바퀴 속도를 낮추세요.

직진 속도가 느린 경우

220~240으로 올리세요

직진(010) 두 값을

느린 쪽 바퀴 60을
80~100으로 올리세요

완만한 커브에서 덜 꺾이는 경우

느린 쪽 바퀴 60을
40으로 낮추세요

급커브에서 이탈하는 경우

느린 쪽 바퀴를 0(정지) 또는
-60(역회전)으로 낮추세요

한쪽 바퀴만 역회전하도록 변경하세요

5 무선 업로드 (OTA)

두 번째 업로드부터는 USB 없이 Wi-⁠Fi로 업로드할 수 있습니다.
완료한 단계에 체크하세요.

파일 삭제 금지

무선 업로드 기능은 코드 안에 있습니다.
ota_ap.h 등의 파일을 삭제하면
이후에는 USB로만 업로드할 수 있습니다.

문제 해결

Wi-⁠Fi 목록에 로봇이 보이지 않는 경우

먼저 코드가 업로드되었는지 확인하세요(1번).
업로드되어 있다면 전원과 배터리를 확인한 뒤 로봇을 재부팅하세요.

비밀번호 오류가 표시되는 경우

비밀번호는 입니다.
영문 소문자와 숫자 0을 정확히 입력했는지 확인하세요.

대시보드에 접속되지 않는 경우
  • 현재 로봇 Wi-⁠Fi에 연결되어 있는지 확인하세요.
  • 주소를 http://과 같이 http://까지 입력하세요.
    https로 접속하면 열리지 않습니다.
  • 휴대폰이나 태블릿은 모바일 데이터를 끈 뒤 다시 시도하세요.
대시보드 연결이 끊기는 경우

로봇 1대당 대시보드는 최대 4개 창까지 연결됩니다.
다른 기기에서 열어 둔 창을 닫으세요.

USB 연결 후 COM 포트가 보이지 않는 경우

데이터 전송용 USB 케이블인지 확인하고 다른 USB 포트에 연결해 보세요.
그래도 보이지 않으면 보드의 USB 드라이버를 설치하세요.

Arduino IDE에 네트워크 포트가 보이지 않는 경우

노트북이 로봇 Wi-⁠Fi에 연결되어 있는지 확인한 뒤 Arduino IDE를 재시작하세요.
